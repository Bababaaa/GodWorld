# God World — Child of Earth

Child of Earth is a story-driven adventure game prototype in the God World setting, developed by Thomas Swayne with AI assistance.

## Project status

The game is in active development. This repository currently serves as a project overview; the playable build and implementation are not yet published here.

## My contribution

I handle story and game design, direct AI-assisted implementation, write and review code, and playtest builds. I use AI assistance throughout development and evaluate the resulting changes through code review, testing, and iteration.

## Implementation

The local project includes a Godot 4.6 implementation using GDScript and an earlier JavaScript browser prototype. Narrative content is shared through JSON exports. Features include dialogue and story progression, inventory, and local save/load with validation.

The JavaScript project includes automated checks for story progression, invalid actions, malformed saves, and content consistency. All 19 JavaScript tests passed in a review on October 14, 2026. That review did not rerun the full native Godot test suite.
